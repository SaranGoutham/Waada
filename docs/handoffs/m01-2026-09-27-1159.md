## Gotchas learned

- **pnpm:** use `npx pnpm@12.6.0 …`, because corepack on Node 22.15 can't start pnpm 12 (see the M00 report).
- **Shared files with other agents' uncommitted edits** (`docs/PROGRESS.md` had M02 and M03 edits): don't `git add` the whole file. Stage only your line. Write `HEAD` content plus your change to a temp file, then `BLOB=$(git hash-object -w tmp)` and `git update-index --cacheinfo 100644,$BLOB,docs/PROGRESS.md`. That's how `d2a556d` was made.
- **`git pull --no-rebase origin dev` can hang for minutes** (network or credentials). Run it in the background. It finished fine on its own this session. Its output mentioned `git reset --hard … to recover`: that is only git's hint text. Never run it.
- **SDK error shapes** (0.10.1):
  - A network failure is a `HindsightError` with `statusCode === undefined`, because the generated client swallows the `fetch` error.
  - `deleteBank` throws a plain `Error` with no status.
  - Recall dates can come back with a `+00:00` offset, which `MemoryHit`'s `z.string().datetime()` rejects. Normalise with `toIsoOrNull`.
- **`getEnv()` treats an empty env var as unset, and real env vars win over `.env`.** So `vi.stubEnv("HINDSIGHT_BASE_URL", "")` simulates "unset" in unit tests.
- **`foundation.test.ts` (M00) has `expect(() => core.createMemory()).toThrow("not implemented: memory")`.** Delete that one line in the Task 4 commit (the M00 report hands it to M01).
