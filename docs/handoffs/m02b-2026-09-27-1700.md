## Approved design (write this up as the spec when the tier opens)
1. `packages/core/src/llm/auth/openrouter-pkce.ts`:
   - `challengeFor(verifier)` and `createPkcePair()`: 32 random bytes as a base64url verifier and an S256 challenge, using `node:crypto`.
   - `startOpenRouterSignIn(callbackUrl)`:
     1. Saves `{ verifier, createdAt }` to `.waada/oauth/openrouter.json`.
     2. Returns `https://openrouter.ai/auth?callback_url=…&code_challenge=…&code_challenge_method=S256`.
   - `completeOpenRouterSignIn(code, deps?: { fetch })`:
     1. Loads the saved verifier. A missing verifier, or one older than 10 minutes, raises a `WaadaError` asking the user to start again.
     2. POSTs `{ code, code_verifier, code_challenge_method: "S256" }` to `https://openrouter.ai/api/v1/auth/keys` and reads `{ key }`.
     3. Maps 400 and 403 responses and network errors to friendly `WaadaError`s.
     4. On success, saves `credentials.openrouter = { apiKey, via: "oauth" }`, `provider: "openrouter"` and the model above, via M02's `getLlmSettings` / `saveLlmSettings`.
     5. Deletes the saved verifier either way (single use).
2. Routes in `apps/web/src/routes/api/auth/openrouter/`. They're thin and need M06's app to exist.
   - `start`: builds the callback URL from the incoming request's origin, then sends a 302 redirect.
   - `callback`: redirects to `/settings/llm?signin=openrouter`, or adds `&error=<safe message>` on failure. No stack traces. `// VERIFY:` the TanStack Start server-route API against its docs.
3. Security: the key and the code are never logged or put in error messages. OpenRouter has no `state` parameter; a forged code fails because it won't match the saved verifier.
4. Tests in `packages/core/test/auth.openrouter.test.ts`, with no network:
   - the RFC 7636 Appendix B test vector (`dBjftJeZ4CVP-mJ92K27uhbUJU1p1r_wW1gFWFOEjXk` → `E9Melhoa2OwvFrEMTJguCHaoeK1t8URWbuGJSstw-cM`)
   - the shape of the sign-in URL
   - a successful sign-in, with `fetch` mocked and a temporary data dir
   - no saved verifier, an expired verifier, a 403, a network error, and a missing code
5. Coordination: add one line, `export * from "./auth/openrouter-pkce.ts"`, to M02's `packages/core/src/llm/index.ts` once M02 is `done`, and note it in the report.
