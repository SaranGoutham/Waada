# M03 Ingest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace the M00 ingest stub with a deduped file→Interaction→memory pipeline plus .eml, Slack-export, transcript, and audio parsers.

**Architecture:** Six focused modules under `packages/core/src/ingest/`: `index.ts` re-exports the §6.6 surface; `pipeline.ts` owns `ingest()` + the `.waada/manifest.json` dedupe store; `parse-files.ts` dispatches by extension; `eml.ts` / `slack-export.ts` / `transcript.ts` / `audio.ts` own one format each. All cross-module types come from `models.ts` (Zod); no `console.log` (use `log.ts`); dates cross boundaries as UTC ISO strings.

**Tech Stack:** TypeScript strict ESM, Node ≥ 22, `postal-mime` (approved S20) for .eml, `node:crypto` sha256 for `file:` sourceIds, Vitest + `FakeMemory`/`FakeLLM` (no network in unit tests).

**Spec:** `tasks/M03-ingest.md` (implements AGENTS.md §6.6). Reference set: `seed/acme` (14 eml + 8 transcripts + 11 Slack days = 33 interactions per `seed/acme/EXPECTED.md`).

## Global Constraints

- TypeScript `strict: true`, ESM, Node ≥ 22, pnpm workspace; format/lint Biome (`pnpm check`), tests Vitest (`pnpm test`).
- Only `packages/core/src/ingest/` files listed in the brief plus `packages/core/test/ingest*.test.ts` and `packages/core/test/fixtures/ingest/*` may be created/edited (plus one-line PROGRESS.md row update and a PROPOSALS.md zip entry).
- Only `packages/core/src/memory/` imports `@vectorize-io/hindsight-client`; only `packages/core/src/llm/` imports `ai`/`@ai-sdk/*`. Ingest takes `Memory`/`LLM` via `deps` params.
- No network in unit tests: `FakeMemory`/`FakeLLM` only. No secrets in code. No `console.log` in `packages/core` (use `log.ts` logger).
- New npm packages need human approval: `postal-mime` is pre-approved (S20); a zip library is NOT — `.zip` gets an error string + a `docs/decisions/PROPOSALS.md` entry, no install.
- Git: branch `dev`, never switch/stash/reset; stage explicit paths only; commits `m03: <imperative>` with no AI attribution; every commit keeps `pnpm check && pnpm test` green.

## Review Focus

- Multipart `.eml` where the text part is empty but HTML is rich → must still yield non-empty content (HTML→text fallback), not an empty Interaction.
- `Date` header with a non-UTC offset (e.g. `+0530`) → stored date must be the UTC instant, not the wall-clock string.
- Slack JSON containing `bot_message` subtypes / `thread_ts` replies / missing `user_profile` → must not crash; fall back to `user` id and still emit one Interaction.
- Transcript front-matter with extra whitespace / `participants: A, B ,C` spacing → participants must be trimmed, never contain empty strings.
- Two files with byte-identical content ingested for different accounts → both kept (manifest keyed by account), same `file:` sourceId in each.
